# HR Analytics & Recruitment Dashboard

## Project Overview
This project focuses on analyzing recruitment and HR data to track key hiring metrics and performance indicators.

## Objectives
- Analyze recruitment funnel and hiring trends
- Track recruiter and department-wise performance
- Identify bottlenecks in hiring process

## Tools & Technologies
- Power BI (DAX, Data Modeling)
- SQL (Joins, Aggregations)
- Excel
- Python (optional)

## Key KPIs
- Total Candidates
- Total Hires
- Time to Hire
- Offer Acceptance Rate
- Recruiter Performance

## Dashboard Features
- Interactive slicers (Department, Recruiter, Source, Application Date)
- KPI cards and trend charts
- Recruiter-wise and department-wise analysis

## Business Insights
- Identified high-performing recruiters
- Highlighted departments with longer hiring cycles
- Improved recruitment visibility through dashboards
